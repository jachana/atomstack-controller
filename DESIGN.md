# Desktop design — 0.15

Operate mode. The user supplied a LightBurn screenshot and requested the same
workspace arrangement. Dark charcoal chrome surrounds a light measured canvas.
This replaces the earlier spacious light panel layout. Native Windows/Tk controls,
Segoe UI, compact labelled tools, and visible keyboard focus remain the interaction
language. No imitation branding or inactive placeholder tools.

Drawing tools run down the left. File/history and numeric X/Y/W/H/angle controls
run across the top. The right dock contains Objects, Cut layers, and Move tabs,
material presets, and fixed Start/Stop/Pause/Resume/Frame/Preview controls.
A persistent red stop is also available in the application header. Canvas rulers
use the same viewport transform as geometry; millimetres and bottom-left origin.
Minimum window 1100×820, default 1440×980. Scrollable object/layer inspectors keep
controls reachable at minimum size. Machine & Jog retains the full keyboard/mouse
navigator and filtered diagnostics. All motion continues through Controller guards.
